# Python-Data-Cleaning-With-Pandas

PREPARANDO DADOS PARA UMA EQUIPE DE MACHINE LEARNING

A preparação dos dados foi feita utilizando a linguagem Python com apoio das bibliotecas Pandas e Numpy.

O objetivo da análise era entender melhor os conceitos de Churn.

CHURN: Churn é um termo utilizado para se referir à taxa de cancelamento de clientes em um determinado período de tempo. Em outras palavras, é a porcentagem de clientes que deixam de usar um produto ou serviço em um determinado período.
